Terminal translations

Kitty Keyboard Protocol shifted Meta events are normalized.

KeysAction / contextCommand
M-S-] / M-S-[Translate to M-} / M-{key-translation-map
M-S-9 / M-S-0Translate to M-( / M-)key-translation-map
M-S-j / M-S-s / M-S-r / M-S-l / M-S-hTranslate to M-J / M-S / M-R / M-L / M-Hkey-translation-map
CIDER’s old C-c C-t prefix is unbound. Ctrl-letter test-map duplicates C-r, C-t, C-a, C-n, C-s, C-l, C-p, C-b, and C-f are removed; plain-letter commands remain. In normal / visual / motion states, the comma alias lets you use these C-c commands through “,”.
